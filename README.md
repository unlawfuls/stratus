# stratus-utils

Java utility library.

- `dev.stratus.hash.Hashes` - SHA-256 / SHA-1 / MD5 hex digests
- `dev.stratus.text.Strings` - blank checks, random alphanumeric strings, Base64 helpers
- `dev.stratus.codec.Hex` - hex encode/decode
- `dev.stratus.math.FastMath` - clamp, lerp, rounding helpers
- `dev.stratus.core.Hstx` - digest matching helpers
